# Code of Conduct

## Our pledge

We want CaseAttend to be a welcoming, harassment-free project for everyone,
regardless of background or identity. We pledge to act in ways that build an
open, respectful, and collaborative community.

## Our standards

Behavior that helps:

- Being kind, respectful, and constructive.
- Welcoming newcomers and differing viewpoints.
- Accepting feedback gracefully and focusing on what's best for the project and
  its learners.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language, publishing others' private information, and other conduct that would
reasonably be considered inappropriate.

## Scope

This applies in all project spaces — issues, pull requests, and discussions —
and when representing the project in public.

## Enforcement

Report unacceptable behavior privately to the maintainer via a GitHub Security
Advisory or by contacting the repository owner directly. Maintainers may remove
contributions or ban contributors for behavior they deem inappropriate. Reports
are handled confidentially.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org).
